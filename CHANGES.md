| Область | Было | Стало |

| Запись экрана | Захват `QScreen.grabWindow` из фонового потока; GIF хранит все кадры в RAM | Захват `mss`/`ImageGrab` без Qt; кадры сразу на диск (ffmpeg, H.264); звук системы + микрофон (WASAPI) с привязкой ко времени; лимиты: длительность, место на диске, память GIF |
| ИИ | Каждый запрос отдельно | История диалога (SQLite, несколько диалогов, «Новый»/«История»), потоковая генерация (SSE), кнопка «Стоп», бюджет контекста |
| Буфер | История в памяти | SQLite, поиск (регистронезависимый для кириллицы), избранное, секреты: DPAPI + маска + автоудаление; записи менеджеров паролей не сохраняются |
| Полка файлов | Пропадала при перезапуске | Хранится в базе, удаление по одному, отсутствующие файлы помечаются |
| Эквалайзер | Синусоиды | FFT системного звука (WASAPI loopback), 4 полосы; запасной вариант — реальный пик устройства |
| Напоминания | Только «ежедневно в HH:MM» | Одноразовые и повторяющиеся (день/будни/дни недели/число месяца/интервал), фразы вроде «через 15 мин», диалог, правка, откладывание, вкл/выкл, удаление; пропущенные помечаются |
| Рабочая область | При выходе ставился «весь экран» (панель задач начинала перекрывать окна) | Исходная область запоминается, восстанавливается при выходе/смене режима и после аварии |
| Потоки | `QClipboard.setText` из потоков OCR/голоса/загрузки; `grabWindow` из потока записи | Только сигналы в главный поток |
| Панель «Управление» | Простые кнопки | Собственная панель: Wi-Fi, Bluetooth, громкость + микшер приложений, устройства звука, яркость, микрофон, камера, энергосбережение, режим Windows |

Данные из `config.json` (`reminders`) переносятся в базу при первом запуске (как «каждый день» — так они работали раньше).

# 5.4 — исправление вылетов (access violation) и издатель

| Область | Что было | Что стало |
|---|---|---|
| Вылеты `0xC0000005` в `comtypes.__del__` | `cast(dev.Activate(...), POINTER(...))` не делает AddRef: исходный и приведённый указатели оба вызывали Release → объект освобождался раньше времени, сборщик мусора падал в случайном потоке (в логах — поток погоды в `ssl._load_windows_store_certs`) | `QueryInterface(...)` в `system/audio_ctl.py` и `modules/spectrum.py`; тест запрещает `cast(` для COM |
| SSL | `ssl.create_default_context()` на каждый запрос: заново читалось хранилище сертификатов Windows, много временных объектов → чаще срабатывал GC | один общий контекст (`core/security.ssl_context`) |
| Эквалайзер | Каждые 2 с создавался и уничтожался `PyAudio()` (полная инициализация PortAudio/WASAPI) только ради имени устройства | смена устройства проверяется через Core Audio (`default_render_id`), запасной путь — раз в 10 с |
| Сборка мусора | COM-мусор мог собираться в любом потоке | `gc.collect()` периодически в COM-потоках (аудио-воркер, наблюдатель устройств, спектр) |
| Издатель | В диспетчере остров был «Python» / Python Software Foundation | лаунчер запускает копию `python.exe` как `IslandPro.exe` с `CompanyName=OlegBFF` в ресурсе версии; `IslandLauncher.exe` собирается с `version_info.txt` |


# 5.5 — ИИ-ассистент с контекстом Windows, интерактивные уведомления

| Область | Было | Стало |
|---|---|---|
| Окно чата | Один текстовый блок и однострочное поле | Пузыри сообщений с Markdown (код, списки, ссылки), потоковый вывод с индикатором «печатает», копирование ответа, вложения-миниатюры, многострочное поле (Enter — отправить, Shift+Enter — перенос), пустое состояние с подсказками, светлая и тёмная тема |
| Закрытие в чате | Клик вне острова сворачивал его | Пока открыта вкладка «Чат», остров не сворачивается (ни от клика вне, ни от ухода курсора). Закрыть: кнопка ▾, Esc, «закрой остров». Тосты показываются внутри чата. Отключается в Настройках → ИИ → «Не закрывать остров в чате» |
| Контекст для ИИ | — | Кнопка «+»: скриншот экрана или области, текст с экрана (Windows OCR), буфер обмена (текст и картинки). Вложения видны чипами и снимаются крестиком. Буфер с похожим на секрет содержимым не отправляется |
| Анализ скриншотов | — | Изображения уходят в мультимодальный формат OpenAI-совместимого API (нужна модель с поддержкой изображений) |
| Команды | — | Правила разбора (без ИИ): «уменьши громкость до 30%», «громче на 10», «выключи звук», яркость, пауза/следующий трек, таймер, «напомни через 15 минут…», «создай заметку…», «открой ютуб / github.com / блокнот / телеграм», «найди в гугле…», «открой заметки», «закрой остров», «не беспокоить», тема, скриншот, OCR, «который час» и др. Числа прописью понимаются |
| Голос | Диктовка в буфер | Кнопка микрофона (в чате и на панели): запись с автоматическим концом фразы (WASAPI, без PyAudio) → команда выполняется или вопрос уходит ИИ. Диктовка в буфер: «надиктуй …» |
| Уведомления: карточка | Ответить / Отложить / Открыть / Прочитано | + кнопки из текста сообщения: «Копировать код», ссылки (по имени сайта), «Копировать номер»; управление музыкой (⏮ ⏯ ⏭) для плееров; быстрые ответы и «ИИ, предложи ответ»; превью картинок (локальные файлы — сразу, по ссылке — по кнопке), просмотр во весь экран |
| Уведомления: группы | Плоский список | История по приложениям: заголовки с числом и непрочитанными, свернуть/развернуть, «прочитано» и «очистить» для всей группы; в очереди карточек сообщения одного приложения стоят рядом |

Ограничения Windows: `UserNotificationListener` отдаёт приложению только заголовок и текст чужого уведомления — без кнопок
действий, полей быстрого ответа и вложений тоста. Поэтому ответ по-прежнему открывает приложение и копирует текст
(опционально вставляет Ctrl+V), а «действия» и «вложения» строятся из содержимого самого сообщения.

Безопасность: команды выполняются только из текста, который вы ввели или сказали. Ответы ИИ, текст с экрана и из буфера
никогда не запускают действия. Картинки по ссылкам из уведомлений не загружаются сами (иначе отправитель узнаёт, что вы
прочитали сообщение) — только по кнопке или с включённой настройкой.

Новые модули: `core/commands.py`, `core/notif_extract.py`, `core/notif_media.py`, `core/vad.py`, `modules/assistant_cmds.py`,
`modules/assistant_ctx.py`, `modules/chat_logic.py`, `modules/voice.py`, `modules/app_finder.py`, `ui/chat_widgets.py`,
`ui/image_viewer.py`. Миграция БД v3: вложения сообщений чата.
